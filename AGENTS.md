# Working with this repository

- Read [`ROADMAP.md`](ROADMAP.md) before planning or claiming completion. It is the authoritative roadmap.
- Read [`docs/DOCUMENTATION.md`](docs/DOCUMENTATION.md) for navigation to existing documentation.
- Preserve the project's existing `master` integration and manual release policy. Do not publish a stable release or change release status automatically.
- Do not treat automated tests as proof of the physical Firefox/Waterfox and Android verification gates documented in the roadmap.
- Never discard unmerged branches or user data during maintenance.
